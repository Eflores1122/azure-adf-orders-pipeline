Linaje de la fila

      

        

          
            

              Paso
              Expresión en df_orders_etl.json
              En esta página
            

          
          
            

              DerivarArchivo
              substringIndex(RawPath, '/', -1)
              FileName es el nombre del archivo elegido o subido.
            

            

              CustomerName
              substringIndex(FileName, '_', 1)
              Se calcula en cada fila. set_customer usa el primer segmento de split por _.
            

            

              EmailTimestamp
              toTimestamp del texto posterior a DeliveryOrder_, patrón yyyyMMdd HHmmss
              Se calcula. Queda nulo cuando el nombre no trae ese timestamp.
            

            

              Quantity
              iif(isNull(Quantity) || trim(Quantity)=='', toInteger(null()), toInteger(Quantity))
              El veredicto es float() de classify_order_row. 10.5 es válida. Esta página no llama toInteger.
            

            

              ForDate
              toDate(ForDate, 'd/M/yyyy'), o nulo si viene vacío
              Se parsea. Una fecha inválida no rechaza la fila.
            

            

              filterDeliveryOrder
              startsWith del prefijo _DeliveryOrder_ y último segmento contra yyyyMMdd'T'HHmmss'Z'
              Se informa con la fecha UTC de hoy. No cambia el conteo de válidas y rechazos.
            

            

              BusquedaCosto
              lookup ProductID == IDProduct, multiple false, pickup any
              Sin diccionario en el repositorio. IDProduct y Sale Cost (USD) no se rellenan.
            

            

              SelectionRows
              split(not(isNull(Quantity))) hacia goodRows y badRows
              Válida o rechazo, con el motivo de explain_order_row.
            

            

              DerivarRechazos
              RejectReason = 'Quantity is NULL'
              Ese texto corresponde a Quantity ausente o vacía. Una Quantity no numérica se rechaza por float() y el JSON no escribe otro motivo.
            

            

              Orders / sinkRejects
              mapColumn hacia dbo.Orders y el CSV de rejects
              Las dos ramas de la tabla. No hay base de datos en esta página.
            

            

              if_hay_rechazos
              sinkRejects.rowsWritten mayor que 0, luego POST
              El cuerpo usa el conteo medido, v_customerName y los marcadores de la canalización.
            

          
        

      


      
Consulta sobre esta corrida

      
Motor de esta página, no Azure SQL. Tablas: run, accepted, rejected. Acepta SELECT, WHERE, GROUP BY, ORDER BY, LIMIT, COUNT y SUM. Los números salen de las filas ya clasificadas.
